# Микросервисная система аутентификации и авторизации на Go 1.25.

## Цель проекта

- Реализовать систему аутентификации и авторизации с JWT.

***

## Архитектура

Планируется 3 сервиса:
- Auth Service — регистрация пользователей, логин, выдача JWT-токенов.
- User Service — CRUD по пользователям, хранение данных в PostgreSQL.
- Gateway Service — API-шлюз, проверка JWT и проксирование запросов к User Service.

## Технологии

- Go 1.25
- PostgreSQL
- Docker, docker-compose
- Prometheus (метрики)
- JSON-логирование, graceful shutdown
